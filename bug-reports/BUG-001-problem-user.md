# SauceDemo Manual Test Cases

## Feature: Login

### TC-LOGIN-001

* Objective: Verify user can login with valid credentials
* Steps:

  1. Open SauceDemo website
  2. Input valid username
  3. Input valid password
  4. Click login button
* Expected Result:
  User successfully redirected to inventory page

---

### TC-LOGIN-002

* Objective: Verify error message appears for invalid password
* Steps:

  1. Open SauceDemo website
  2. Input valid username
  3. Input invalid password
  4. Click login button
* Expected Result:
  Error message displayed
